# 词趣 WordFun

一个纯网页的英语单词学习应用：内置知识库按天规划每天学什么，通过多种题型练习，并用间隔重复（Leitner 盒子）科学安排复习。单词只保留「单词 + 词义」两项。

## 如何使用

1. 用 **Chrome 或 Edge** 双击打开 `index.html` 即可，无需安装任何东西、无需联网。
2. 首次打开会自动载入内置知识库（`data/` 下的 CSV 打包而成），词库即就绪。
3. 数据保存在浏览器 localStorage 中（本机、本浏览器内），换浏览器或清除浏览器数据会丢失进度 —— 请定期在「设置」中导出 JSON 备份。
4. 建议把整个文件夹放在固定位置，用浏览器书签收藏 `index.html`。

## 手机上使用

手机是主要使用场景。有两种打开方式：

**方式一（临时用，同一 Wi-Fi）**：电脑上双击 `启动手机版.bat`，保持窗口开启，手机会显示一个 `http://192.168.x.x:8000/` 地址；手机连同一 Wi-Fi，用浏览器打开这个地址即可。首次运行时若弹出防火墙提示，请选择「允许访问」。电脑本机也可以用 `http://localhost:8000/` 打开。

**方式二（长期用，随时随地）**：把整个项目部署到静态托管（GitHub Pages / Gitee Pages 等），手机浏览器直接访问网址，不依赖电脑。界面已按手机单列布局适配（触控目标 ≥44px、底部弹层、安全区适配）。

- **添加到主屏幕**：Android Chrome 菜单 →「添加到主屏幕」；iOS Safari 分享 →「添加到主屏幕」。之后可像 App 一样全屏打开（图标为天蓝底白色 W）
- **数据说明**：数据按「浏览器 + 地址」分别存储，手机与电脑互不同步 —— 在「设置 → 数据备份」导出 JSON，再在另一台设备导入

## 知识库（按天规划）

网站的单词来自「知识库」：`data/` 目录下的 CSV 文件，部署前用脚本打包进 `data/kb.js`。

- 每个 CSV 的文件名（去掉 `.csv`）就是该知识库的名字，站内按名去重导入
- CSV 格式为三列：`所属天/单元,单词,词性及中文释义`（第一行是表头）
  - 第 1 列标明天数，如 `第1天 Unit 1 Lesson 1`，只取其中的「第 N 天」数字
  - 单词列带 `*` 的派生词会自动去掉 `*`；`behavio(u)r`、`practise/-ice` 等变体写法可直接导入；`résumé` 自动归一为 `resume`，`lie①` 归一为 `lie`
- 「今天」= 还没有学完的最小天数（第 1 天开始，学完自动进入第 2 天……），首页会显示「今天 · 第 N 天」
- 首页的「学习天」下拉可**直接跳到任意一天**（第 1～N 天）自主学习；选「自动 · 跟随进度」则恢复按顺序推进
- 一场练习 = 到期复习词（占最多一半）+ 当天新词

**添加新知识库**：把新的 CSV 放进 `data/`，运行 `node tools/make-kb.js` 重新生成 `data/kb.js`，再重新部署即可。新知识库的天数会自动接在前一个之后，不会和第 N 天冲突；已学进度保留。

## 导入单词

「词库」页 → 「批量导入」也支持手动追加单词（粘贴或上传 CSV/TXT 文件，1MB 以内，UTF-8 或 GBK 编码均可）：

| 格式 | 写法 | 说明 |
|---|---|---|
| 带天数 | `第1天 Unit 1,act,v.行动` | 三列：天数 + 单词 + 词义 |
| 简单 | `apple, 苹果` | 两列：单词 + 词义（无天数 = 自由词，随时可学） |

- 单词自动转为小写；支持 CSV 引号转义（如 `"per cent","百分之……"`）和中文标点
- 第一行若是表头（如 `所属天/单元,单词,词义`）会自动跳过
- 重复导入同一个单词：词义会合并（以「；」分隔），**已学进度保留**
- 不合法的行会被跳过，并在导入结果里逐行说明原因

## 练习机制

- **三种题型**：看词选义、看义选词、拼写；每 10 题左右有一轮「连连看」配对
- **跳过**：练习中可点「跳过此单词」跳过当前词（不判定、不影响进度，该词下次再学）
- **间隔重复**：答对 → 升入更高盒子（1 / 3 / 7 / 14 / 30 天后复习）；答错 → 回到待复习，本场末尾再问一次
- **进度可续**：练习中随时退出或刷新，进度自动保存，回到首页可点「继续上次练习」接着学
- 单词发音功能暂未启用（听音题已移除，发音代码保留在 js/tts.js 备用）

## 文件结构

```
index.html             应用入口（双击打开）
manifest.json          Web App 清单（添加到主屏幕）
icons/                 应用图标（PNG）
css/style.css          样式（天蓝 + 白，极简风格，移动端适配）
data/*.csv             知识库源文件（可增删）
data/kb.js             打包后的知识库数据（由 tools/make-kb.js 生成，勿手改）
js/storage.js          数据层：localStorage 读写、词库、设置、统计、备份、会话/知识库记录
js/srs.js              间隔重复算法与按天会话选词
js/questions.js        三种题型生成器
js/tts.js              Web Speech API 发音封装（暂未启用，页面未加载）
js/import.js           文本/CSV 解析与导出
js/ui.js               视图渲染、模态框、图表
js/app.js              应用编排、练习会话状态机、知识库载入
test.js                逻辑层测试（node test.js）
server.js              本地服务器（手机访问用）
启动手机版.bat          双击启动本地服务器（Windows）
tools/make-icons.js    图标生成脚本
tools/make-kb.js       知识库打包脚本（node tools/make-kb.js）
tools/import-preview.js 导入预览脚本（node tools/import-preview.js <csv>）
```
