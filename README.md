# 词趣 WordFun

一个纯网页的英语单词学习应用：导入你自己的单词，通过多种题型练习，并用间隔重复（Leitner 盒子）科学安排复习。

## 如何使用

1. 用 **Chrome 或 Edge** 双击打开 `index.html` 即可，无需安装任何东西、无需联网。
2. 数据保存在浏览器 localStorage 中（本机、本浏览器内），换浏览器或清除浏览器数据会丢失词库 —— 请定期在「设置」中导出 JSON 备份。
3. 建议把整个文件夹放在固定位置，用浏览器书签收藏 `index.html`。

## 手机上使用

手机是主要使用场景。有两种打开方式：

**方式一（临时用，同一 Wi-Fi）**：电脑上双击 `启动手机版.bat`，保持窗口开启，手机会显示一个 `http://192.168.x.x:8000/` 地址；手机连同一 Wi-Fi，用浏览器打开这个地址即可。首次运行时若弹出防火墙提示，请选择「允许访问」。电脑本机也可以用 `http://localhost:8000/` 打开。

**方式二（长期用，随时随地）**：把整个项目部署到静态托管（Gitee Pages / GitHub Pages 等），手机浏览器直接访问网址，不依赖电脑。界面已按手机单列布局适配（触控目标 ≥44px、底部弹层、安全区适配）。

- **添加到主屏幕**：Android Chrome 菜单 →「添加到主屏幕」；iOS Safari 分享 →「添加到主屏幕」。之后可像 App 一样全屏打开（图标为天蓝底白色 W）
- **数据说明**：数据按「浏览器 + 地址」分别存储，手机与电脑互不同步 —— 在「设置 → 数据备份」导出 JSON，再在另一台设备导入（双击打开的本地文件、localhost、局域网 IP、线上网址，四处数据各自独立）
- 若浏览器不支持语音朗读，听音题会自动替换为看词选义，不影响学习

## 导入单词

「词库」页 → 「批量导入」支持两种方式：

- **粘贴文本**（每行一个词）
- **上传 CSV / TXT 文件**（1MB 以内；UTF-8 或 GBK 编码均可，Excel 另存的 CSV 直接可用）

每行格式（任选其一）：

| 格式 | 写法 | 说明 |
|---|---|---|
| 简单 | `apple, 苹果` | 单词 + 词义 |
| 完整 | `apple \| /ˈæpl/ \| n. 苹果 \| I ate an apple.` | 单词 + 音标 + 词义 + 例句 |

- 单词只允许英文字母（可含空格、连字符、撇号），自动转为小写
- 支持 CSV 引号转义（如 `"hello, world","你好"`）和中文标点（，｛“”｝自动归一）
- 第一行若是表头（如 `word,meaning` 或 `单词，词义`）会自动跳过
- 重复导入同一个单词：词义会合并（以「；」分隔），**已学进度保留**
- 不合法的行会被跳过，并在导入结果里逐行说明原因

## 练习机制

- **四种题型**：看词选义、看义选词、听音辨义、拼写；每 10 题左右有一轮「连连看」配对
- **间隔重复**：答对 → 升入更高盒子（1 / 3 / 7 / 14 / 30 天后复习）；答错 → 回到待复习，本场末尾再问一次
- **每场组成**：约 80% 到期复习词 + 20% 新词（新词数量受「每日新词」上限约束，到期词不足时由新词补满）
- 听音题依赖系统语音（Web Speech API，Windows 自带 en-US 语音），不可用时自动换成看词选义

## 文件结构

```
index.html          应用入口（双击打开）
manifest.json       Web App 清单（添加到主屏幕）
icons/              应用图标（PNG）
css/style.css       样式（天蓝 + 白，极简风格，移动端适配）
js/storage.js       数据层：localStorage 读写、词库、设置、统计、备份
js/srs.js           间隔重复算法与会话选词
js/questions.js     四种题型生成器
js/tts.js           Web Speech API 发音封装
js/import.js        文本/CSV 解析与导出
js/ui.js            视图渲染、模态框、图表
js/app.js           应用编排与练习会话状态机
test.js             逻辑层测试（node test.js）
server.js           本地服务器（手机访问用）
启动手机版.bat        双击启动本地服务器（Windows）
tools/make-icons.js 图标生成脚本（node tools/make-icons.js）
```
